
# PRD (Product Requirement Document)

## Goal
Help users quickly track daily expenses without complexity.

## Main Problem
Most expense apps are bloated and slow.
Users just want:
- quick add
- category
- monthly total

## Core Features
- Add expense
- Edit/delete expense
- Categories
- Monthly total
- Expense history
- Basic chart
- Search/filter

## Optional Features Later
- Export CSV
- Budget warning
- Dark mode themes
- Backup/restore

## User Flow
1. Open app
2. Tap + button
3. Enter amount
4. Select category
5. Save
6. View totals/charts

## Monetization
- AdMob banner
- Remove ads purchase later
